# Search-First Demo

This directory contains the static search-first prototype and its build helpers. It is useful for
research and product exploration, but it is **not** the live Jahia chat widget.

The deployed widget is built from the separate
[`smomin/algolia-central-chat-widget`](https://github.com/smomin/algolia-central-chat-widget)
repository and published to Jahia under the deployment contract at
`docs/design/search-experience/discovery-engagement/OPERATING-CONTRACT.md`.
