## Why this runs early

The claim *"no B2B SaaS or enterprise software company has done search-led marketing-site
navigation"* is currently **unproven** and it is in the pitch. This unit is a premise test,
not background research. Three possible verdicts, and each changes the project:

- **Nobody tried** → the novelty claim earns its place in the brief. Say so with evidence.
- **Someone tried and it worked** → strongest possible proof point. Reframe the pitch
  around it and it stops being a risky bet.
- **Someone tried and retreated** → the single most important fact in the project.
  Find out *why* they retreated; that reason is what WU-10 must answer and what a
  reviewer will raise first.

The plan is explicit: this claim either earns evidence here or **it leaves the brief.**

## Inputs

- Five starting sources are already listed in
  `docs/90-archive/2026-08-05-search-first-algolia-com-plan.md` — start there, do not
  re-derive them.
- `detect-search` skill — for any candidate site still live, identify its search stack.
- The Wayback Machine is the primary tool for "tried and retreated": a company that
  reverted will have no press release about it. Diff homepage snapshots over time.

## Method

1. Read the archive's five sources first.
2. Build a candidate list. Look at: developer-tool companies (Stripe, Vercel, Twilio,
   Algolia's own peers), enterprise search vendors' own sites (they have the strongest
   incentive to dogfood), Atlassian, Shopify's dev surfaces, AWS, docs-first companies.
3. For each candidate: was search the *primary* nav mechanism on the marketing site, or
   just a prominent search box? **Hold the bar high.** A big search field on a hero is
   not search-led navigation. Define the bar in writing before judging any candidate.
4. Wayback-diff any candidate that looks like it once did this and no longer does.
5. For each real attempt found, record: what pattern · when · still live? · public
   evidence of outcome · if retreated, the stated or inferable reason.
6. Write the verdict as an explicit statement, not a hedge.
7. **Stop at 3 hours.** Report what the search covered and what it did not. A bounded
   negative is a valid result; an unbounded search is not.
