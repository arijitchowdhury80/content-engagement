**Read this first:** the plan treats this unit as background. It is not. This overlay
is the strongest existing precedent for the entire thesis — Algolia already ships a
search-led discovery surface on its own site. Treat it as the baseline the concept
*promotes to the homepage*, not as competitor research.

## Method

1. Open `https://www.algolia.com`, trigger the overlay. Screenshot the pre-query state.
2. Enumerate **source filters**. WU-02 found 8 named content sources in the site's own
   taxonomy — Documentation, Support, Blog, Website, Developers, Resources, Academy,
   Customer Stories. Confirm against the live overlay and record each one's result count.
3. Capture each state, screenshotting every one:
   pre-query · typing/autocomplete · post-query results · AI-mode answer · zero-result.
4. Record **result groupings** — how results cluster, and by what attribute.
5. Record **result metadata** shown per hit (title, breadcrumb, type badge, snippet, date?).
   Note specifically whether the overlay displays a breadcrumb — the *pages* have none,
   so if the overlay synthesises one, that is a finding worth its own line.
6. Record **expansion paths**: "show more", per-source drill-in, full results page.
7. Record the **AI-mode prompts** and whether answers are cited, extractive, or generative.
8. Note what the overlay does *not* do — the gaps the concept must close.
9. Map each of the 8 non-negotiable journeys: can the current overlay complete it today?
   This is the table WU-20 will measure against.
