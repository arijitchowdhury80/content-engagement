## Method

1. Load `ia-map.json`; freeze the vocabularies for the 3 axes actually being built here
   (intent, audience, conversion_action). Write them down before classifying.
2. Classify all current records for those 3 axes only. Batch by Chapter 1's `page_type`
   cluster — reuse the clustering, don't re-derive it.
3. Allow multi-value where honest (a page can serve developer *and* marketer). Decide
   single- vs multi-value **per axis** and record the decision — it becomes the Algolia
   facet type in WU-15.
4. Every record must carry all six axes in the output (3 built + 3 reused from Chapter 1).
   Use an explicit `unknown` value rather than a null on the 3 built axes, so coverage
   is measurable. The 3 reused axes already have Chapter 1's three-state model
   (resolved / not-applicable-omitted / unknown) — preserve it, don't collapse it.
5. Emit the **facet schema** WU-15 consumes: attribute name, single/multi, and whether it
   needs `searchable()` or `afterDistinct()` — for all 6, noting which 3 are new writes
   and which 3 are pass-through reads from Enhanced.
6. Spot-check: sample 20 records and hand-verify the 3 built axes (the reused 3 already
   have Chapter 1's own measured error/coverage numbers — don't re-verify those). Record
   the observed error rate on what's actually new here.
