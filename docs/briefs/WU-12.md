## Method

**Run `[43]` first. Its verdict scopes everything below it, and WU-13 and WU-18 wait on it.**

1. `[43]` **Agent Studio capability.** Inspect the `ps_chat_*` indices — settings, record
   shape, what they appear to back. Check the dashboard/API surface for Agent Studio.
   Then produce a **written capability verdict** answering: can we build a real agentic
   layer on this account, bounded, for a public demo — yes, no, or partially?
   **If Agent Studio has no public documentation, say so plainly rather than inferring
   capability.** An honest "unknown" here is worth more than a confident guess, because
   WU-18 will either build on it or label it, and a wrong verdict means shipping implied
   capability that does not exist.
2. `[37]` Agent taxonomy: concierge · product specialist · industry/use-case specialist ·
   developer/integration · academy/education · support · sales/solution consultant.
   Do not create seven agents because seven are listed — justify each or merge it.
3. `[38]` Routing logic: what intent, role, query, click, or behavioural signal activates
   each agent. Must line up with WU-11's query-intent taxonomy; if they disagree, one is wrong.
4. `[39]` Content access per agent — website, product, docs, support, blog, academy,
   customer stories, tools, pricing, security, integrations, events, demo videos.
   Produce this as a **matrix**, agent × source, because `[42]` guardrails and WU-13's
   governance both read from it.
5. `[40]` Answer formats: chat response · content cards · guided facets · recommended
   journey · proof bundle · implementation plan · sales handoff summary.
   ⚠ Apply the Spectrum lesson: an agent that returns page links instead of synthesised
   answers reads as broken. Specify depth expectations per format.
6. `[41]` Handoff rules: stay generalist / bring in specialist / offer human contact.
7. `[42]` Trust guardrails: citations, source visibility, confidence, escalation,
   compliance boundaries, support boundaries.
8. `[44]` Map each of the 8 journeys to its agent flow.
