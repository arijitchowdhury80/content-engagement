2. ~~Re-type the 57 `other` records~~ — **not applicable.** That was a crawl-classifier
   artifact. Chapter 1's `page_type` is measured at 100% coverage on required records;

   records) rather than page content. Full body-structure analysis waits for Chapter 2.

   against Enhanced's current record set — the old 62.6%/6.8% split was measured on
   the crawl's 2,322 records (23% site coverage) and should not be reused as-is. State
   the new ratio from the live 12,114-record set.
6. **`[17]` The tension.** Compare the explicit nav taxonomy against the implicit
   search-source taxonomy — now cleaner to check, since Enhanced's `source` facet
   already gives clean, current counts for all 8 sources (Documentation 4,337, Blog

7. **Must-preserve destination list.** Every URL that cannot lose its addressability —
   pull from Enhanced's full URL set (12,114 current, more complete than the crawl's
