## Method

1. `[WU-14.2]` **Define the two frames + one optional capability layer.**
   Per the plan's naming: Frame 1 = **CMO wedge**, Frame 2 = **search-first north star**.
   Frame 1 is the credible near-term change a CMO could actually approve. Frame 2 is the
   destination. State plainly what each is *for* — they are arguments, not just layouts.
2. `[WU-14.3]` **Per frame, define all seven surfaces:** homepage · search expansion · results ·
   product page · pricing path · developer path · contact-sales path.
3. `[WU-14.4]` Agentic flows — **only** the flows WU-12's verdict permits. If the verdict says
   "designed, not real," define them as designed and say so here.
4. `[WU-14.1]` **Decide the agentic layer's role in the demo:** real / bounded / labeled
   future-state. Write the decision and the reason. This is the honesty commitment that
   WU-18 executes and that stops the demo implying capability that does not exist.
5. `[WU-14.5]` **REFRAMED — define the REAL index schema.** The archive said "data model for
   mocked results." Mocks fail acceptance criterion 1. Define the actual Algolia record
   schema WU-15 will build: attribute names, types, which are searchable, which are
   facets (from `facet-schema.json`), which are retrieved for display, ranking attributes.
   This is a contract; WU-15 implements it verbatim.
6. `[WU-14.6]` What must be clickable vs illustrative. Be honest and specific — an illustrative
   region that looks clickable is the thing that embarrasses a live demo.
7. **The 8-journey matrix.** Build it explicitly: 8 rows × 2 frames, each cell naming the
   path. Any empty cell means the frame is not done.
