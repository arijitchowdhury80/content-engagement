## Scope discipline — read this before starting

The archive's numeric bars — **300ms p95, $0.01/session, 1000-prompt suite** — are
recorded here as **launch gates for a future build.** There is no launch to gate.
**They do not block this demo.** This distinction is what keeps this unit finite; the plan
states it explicitly and it is easy to lose. Write the gates down as future criteria and
move on. Do not build a 1000-prompt eval suite for a concept demo.

What this unit *is* for: having a written, credible answer when someone from Security or
Legal asks "what happens when a competitor prompt-injects your public agent." That answer
is a deliverable of the pitch, not a prerequisite of the prototype.

## Method

1. `[WU-13.4]` **Threat model.** Prompt injection · jailbreaks · competitor manipulation ·
   false public claims · screenshot attacks · scraping · bot abuse · deliberate LLM cost
   attacks. For each: attack · likelihood · impact · mitigation · residual risk.
   The **screenshot attack** deserves real attention: a competitor makes Algolia's own
   public agent say something damaging and posts the image. There is no recall. Mitigation
   is mostly prevention plus refusal design.
2. `[WU-13.2]` Public-agent safety spike — actually try the attacks against whatever exists,
   rather than reasoning about them. Record what happened.
3. `[WU-13.3]` Latency spike — measure. First-useful-response time, instant-search-first
   response model, progressive generation, fallback states. Real numbers from a real query.
4. `[WU-13.1]` Confirm the precommitted thresholds. Record them as **future launch gates**, with
   that label.
5. `[WU-13.5]` Anonymous usage controls: rate limiting, quotas, bot detection, WAF/CDN,
   abuse monitoring, caching, graceful degradation.
   Note: algolia.com already sits behind Cloudflare — that is an existing control to build on.
6. `[WU-13.6]` Per-layer latency budgets: search suggestions · intent detection · agent routing ·
   retrieval · generation · specialist handoff · full answer render. Must sum to something
   defensible against the criterion-3 "faster than today" claim.
7. `[WU-13.7]` Fallback UX: instant results first → streaming answer → cached answer →
   curated links → static page. **Design the demo so the fallback is the default path if
   the agent is slow.** A demo that hangs in front of an exec is worse than one with no agent.
8. `[WU-13.8]` Regulated/high-risk answer categories: pricing · security · compliance · legal
   terms · roadmap · customer claims · benchmark claims · competitive claims · procurement.
9. `[WU-13.9]` Source-of-truth and approval workflow per category.
10. `[WU-13.10]` The four-way line: generate freely / extractive+cited / route to approved page /
    hand to human. Every category from `[WU-13.8]` lands in exactly one bucket.
    **Pricing and competitive claims almost certainly must not be freely generated.**
11. `[WU-13.11]` Eval harness *requirements* — golden conversations, adversarial prompts, claim
    accuracy, routing, latency, refusal, regression. Requirements, not the harness itself.
12. `[WU-13.12]` Ongoing quality loop: transcript sampling, thumbs, conversion outcomes, human
    review queue, incident reporting, rollback, content freshness.
