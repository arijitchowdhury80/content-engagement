# WU-18 — Agentic layer: real or designed

Reasoning: `docs/05-execution-plan.md` § WU-18 · Asana `1217199734241960`

Tier: Sonnet · Blocked by: **WU-12's capability verdict**

## The one rule

**Never imply capability that does not exist.** This unit has two legitimate outcomes and
one forbidden one:

| Outcome | When | What ships |
|---|---|---|
| **Real** | WU-12 verdict says Agent Studio can back a bounded public demo | A working agentic layer, scoped to what the verdict permits |
| **Designed** | Verdict says no, or unknown | A designed layer with an **honest on-screen label** |
| ❌ Forbidden | — | A layer that looks real, isn't, and is unlabelled |

The forbidden outcome is the one that damages Arijit's credibility in the room, which is
the entire asset this project is building. A labelled future-state layer costs nothing;
an exec discovering mid-demo that the agent is fake costs everything.

## Method

**If REAL:**
1. Build only the flows WU-12's verdict permits, and only the agents WU-12's taxonomy kept.
2. Ground on the WU-15 index. Citations visible — `[WU-12.6]` guardrails are requirements.
3. Enforce the `[WU-13.10]` four-way line: generate freely / extractive+cited / route to approved
   page / hand to human. Pricing, security, compliance, competitive claims route or extract.
4. Implement the fallback chain first, then the agent. Instant results must render before
   any generated answer.
5. Apply the Spectrum depth lesson: an agent that answers with a list of page links reads
   as broken. Specify and test for synthesised, grounded answers.
6. Test the adversarial cases from WU-13's threat model — at minimum prompt injection and
   a competitor-manipulation attempt. Record what happened.

**If DESIGNED:**
1. Build the interface faithfully to WU-12's model, with scripted or pre-computed responses.
2. **Label it on screen.** Visible, not a footnote — something a reviewer reads without
   asking. e.g. "Concept: agent responses illustrate the proposed experience."
3. Keep the scripted answers factually correct and grounded in real corpus content. A fake
   agent saying something false about Algolia is still a false public claim.
4. Document precisely what is designed vs real in the README, so WU-21's talk track can
   state it out loud rather than being caught by it.
