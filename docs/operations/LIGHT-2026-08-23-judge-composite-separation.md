# Judge Composite Separation

## Scope

Change deterministic aggregation and presentation only. The Agent Studio judge agents, model, prompts, evidence packet, and four rubric dimensions remain unchanged.

## Root Cause

The runtime calculated valid panel dimension means, then replaced the displayed composite with the lower of the three-dimension quality mean and a grounding severity cap. This made a review warning look like an overall answer score.

## Required Invariant

- `composite` is always the arithmetic mean of the displayed panel means for Grounding, Completeness, Depth, and Relevance.
- Grounding consensus still controls the separate review status and flagged-claim presentation.
- Grounding findings never overwrite the composite or its score tone.

## Validation

- Unit fixture: `6.0 + 7.7 + 6.3 + 8.0`, divided by four, displays `7.0`.
- Consensus grounding fixtures retain their findings and review status without applying a numeric cap.
- Browser tests verify the answer remains visible, the warning remains visible, and the displayed score follows the four-dimension mean.
- Jahia deployment uses immutable assets, readback hashes, and the existing rollback manifest.

## Rollback

Restore the previous complete judge runtime release using the rollback manifest generated by `tools/deployment/deploy_judge_v2_jahia.py`.

## Prevention Heuristic

Review state may annotate a score, but it must never silently replace independently displayed score arithmetic.
