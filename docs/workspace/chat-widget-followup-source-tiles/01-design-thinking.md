Design thinking notes

Mental model:
The answer is the primary artifact. The follow-up question is a guided next step, not part of the answer prose. Sources are evidence metadata below the next step.

Information tiers:
- Primary: answer body, unchanged and flat.
- Secondary: follow-up discovery question, elevated as a tactile prompt tile directly after the answer.
- Supporting: source category pills and source links, visually rich but smaller than the follow-up.

Interaction flow:
1. User reads the answer.
2. User sees one elevated follow-up prompt as the next best question.
3. User can click the question to copy/ask through the existing handler.
4. User can inspect source categories and expand source details below.

Cognitive load:
Visible chunks after an answer should remain under five: answer, follow-up prompt, source pills, optional judge badge, composer.

Emotional arc:
Flat answer builds clarity. The follow-up tile should feel intentional and concierge-like. Source pills should feel trustworthy and inspectable without shouting.

Pre-mortem:
- Risk: 3D/glass becomes noisy. Mitigation: use one soft glass tile and small pastel source chips.
- Risk: follow-up competes with answer. Mitigation: place after answer, use smaller copy and restrained label.
- Risk: source chips lose legibility. Mitigation: preserve high-contrast labels/counts and use light gradients only.
- Risk: mobile crowding. Mitigation: flex-wrap source pills and keep follow-up full-width.
