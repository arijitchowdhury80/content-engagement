What counts as an API call, keystrokes, filters applied, or page loads, and does that change how I should configure rate limiting to control cost?

TL;DR

Yes. Almost every interaction that asks an Algolia index for data can count as a billable search request.

Details

Autocomplete can send a request on each keystroke, filters can trigger new searches, and page loads can initialize queries automatically.

The cost strategy should focus on debouncing, bot protection, caching, and search keys scoped to the right usage, not blocking legitimate search behavior.
