What counts as an API call, keystrokes, filters applied, or page loads, and does that change how I should configure rate limiting to control cost?
TL;DR

Most user-facing interactions that ask Algolia for data can count as billable search requests. Rate limiting should control repeated requests, not block legitimate search behavior.

Example: autocomplete can send a request on each keystroke, filters can trigger new searches, and page loads can initialize queries. The cost strategy should focus on debouncing, bot protection, caching, and keys scoped to the right usage.
