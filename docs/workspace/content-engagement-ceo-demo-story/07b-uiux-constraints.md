# UI/UX constraints

The configured UIUXDesignSOP path was unavailable during this build. The artifact therefore uses the repo context, the existing team UAT constraints, and the Algolia presentation skill's brand rules.

## Applied constraints

- Use Sora and Algolia marketing colors.
- Keep one hero message and a four-act executive narrative.
- Use compact route, screen, evidence, and fallback blocks for scanning.
- Ensure mobile layout at 375px with no horizontal overflow.
- Keep focus states visible and interactive targets at least 44px.
- Avoid claims that old evidence proves the current live build.
- Use historical screenshots as labeled review references, not final proof.
