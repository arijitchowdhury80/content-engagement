# Team Demo and UAT Briefing - UI/UX Constraints

- Exactly eight slides and one visible slide at a time.
- Keyboard support: Left, Right, Page Up, Page Down, Space, Home, and End.
- Visible previous, next, slide position, and section controls.
- No forms, checkboxes, status selectors, task assignments, or feedback storage.
- Each category slide contains exactly two scenarios.
- Tester autonomy is visible; no required question or response.
- Algolia visual language: `#003dff`, white, cool lavender, dark ink, DM Sans.
- Minimum control target: 44px. Strong focus state and reduced-motion support.
- Validate desktop at 1440x900 and mobile at 390x844.
- Long trigger names wrap without horizontal overflow.
- The canonical Markdown remains the detailed source of truth.
