# How Judges Work

Canonical diagram: [`How Judges Work.png`](How%20Judges%20Work.png)

## Content Contract

- Stages: Freeze, Review, Score, Verify, Combine, Explain.
- Every judge receives the same frozen evaluation packet.
- The Skeptic, Referee, and Advocate are the same Agent Studio actor with different role expressions and labels.
- Every judge scores Grounding, Completeness, Depth, and Relevance from 0 to 10.
- Deterministic code validates structure, identity, references, and arithmetic.
- At least two valid judge reports are required.
- Consensus unsupported claims are flagged for review.
- The composite remains uncapped; grounding concerns remain separately visible.
- Judging is asynchronous and never hides, delays, or replaces the answer.
