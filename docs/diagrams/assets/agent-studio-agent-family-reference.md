# Agent Studio Agent Family Reference

## Purpose

This is the shared visual canon for Agent Studio agents across the Content Engagement diagram family. Different jobs use the same underlying agent design.

## Canonical Base Actor

- White mechanical head and torso with restrained charcoal ink linework.
- Rounded navy faceplate with two simple luminous eyes.
- Circular integrated ear discs.
- Blue collar accent.
- Small white chest badge carrying the exact official Algolia symbol.
- Editorial hand-drawn treatment with pale watercolor accents.
- Natural proportions; no mascot, toy, or science-fiction styling.

## Role Layer

The chassis never changes. A role may change only:

- facial expression;
- posture;
- role label;
- one functional prop or surrounding artifact.

| Role | Expression | Functional cue |
|---|---|---|
| Greetings Agent | Warm and welcoming | Greeting and choice bubbles |
| Orchestrator | Focused and attentive | Visitor context bundle or full-story book |
| Skeptic | Restrained frown | Risk review sheet |
| Referee | Neutral straight mouth | Rubric or scoring sheet |
| Advocate | Restrained smile | Value review sheet |

## Brand Invariant

Every depicted Agent Studio agent carries the same exact repository-owned Algolia symbol in the same chest-badge location and relative scale. Generated or approximated logos are not accepted for canonical publication.

Place any two diagrams side by side. The Agent Studio actors must be recognizable as the same family before reading their labels. If the base silhouette, faceplate, ear discs, torso, collar, or badge placement changes, reject the new diagram.
