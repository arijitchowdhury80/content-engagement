- Stages: Browse, Decide, Engage, Continue.
- Stage 1 distinguishes optional durable browser profile from primary current-visit memory.
- Stage 2 shows compiler context creation and deterministic controller outcomes.
- Stages 3 and 4 both receive the qualified moment and visitor context from Stage 2.
- The Greetings Agent and Orchestrator share one canonical Agent Studio actor design.
- Algolia ownership marks identify Agent Studio and chat-widget components.
- The handoff is code, not an agent.
- The Orchestrator receives one visitor-story notebook; no unexplained secondary artifact is present.
