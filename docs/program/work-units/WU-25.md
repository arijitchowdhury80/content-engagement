## This unit is a measurement, not a demo

Acceptance criterion 3: **faster to destination than today's algolia.com on ≥5 of 8
journeys, measured.** The plan is explicit — *if it fails, report the failure rather than
reframing it.* A validation unit that concludes "it feels faster" has failed its own DoD.

Measure the same thing both sides: **click count** and **time to destination**, for each of
the 8 journeys, on the deployed URL and on live algolia.com, desktop and mobile.

## Method

1. `[WU-25.2]` Write the validation checklist first — usability, responsiveness, narrative
   clarity — so measurement is not improvised per journey.
2. Build one Playwright harness that runs the same journey definition against both sites.
   Same start condition (cold load, no cookies), same success condition (arrival at the
   destination page), same clock. **Asymmetric measurement is the easy way to produce a
   flattering fake result** — a harness both sides share is the guard.
3. Run each journey ≥3 times per site per viewport and take the median. A single timing is
   noise.
4. Record per journey: clicks, seconds, success/fail, screenshot of the destination.
5. Do desktop **and** mobile. Criterion 5 is a hard requirement, and a search-led layout
   is where mobile most often quietly breaks.
6. Test the zero-result and ambiguous-intent states from WU-16 `[WU-16.8]` — the plan flags
   this as most likely to be attacked in a live demo.
7. Test the adversarial/embarrassing cases: a competitor's name, a hostile query, a typo,
   a query with no answer in the corpus.
8. `[WU-25.1]` **Usability test, ≥5 participants** across buyer / developer / existing-customer.
   *(Arijit — human, may block.)* This is **directional evidence, explicitly not
   statistically valid.** Label it that way in the report; five users is not a study.
9. Write the result honestly. If fewer than 5 of 8 journeys are faster, that is the finding.
   Report which ones lost and by how much — that is more useful than a pass, because it
   tells WU-26 what not to demo.
