## Method

1. Inventory what actually arrived. Write down what is missing before analysing.
2. For each of `[WU-09.2]`–`[WU-09.13]`, answer the question and **cite the report name + date range**.
3. Separate measured from estimated in the prose. Never present an estimate as a measurement.
4. Compute the numbers the demo will be judged against:
   - today's click-count and time-to-destination for each of the 8 journeys `[WU-09.11]`
     → this is the **baseline for acceptance criterion 3**, which requires the demo be
     measurably faster on ≥5 of 8. WU-25 measures against these exact figures.

5. Carry over the 29-metric instrumentation baseline from the archive as a named section.
6. Where the data cannot answer a question, write "the data does not answer this" and
   move on. Do not fill gaps with plausible numbers.
