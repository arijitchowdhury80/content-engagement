# Enrichment Evidence

Compact, reviewable validation evidence for corpus/index enrichment.

Generated run directories, per-record JSONL payloads, fetched page caches, snapshots, and batch
outputs are intentionally not committed. Keep those local during execution; promote only compact
summaries or human review packets here.

## Sets

- `20260810-blog/` - reviewed Blog enrichment reports and write packets from August 10, 2026.
- `20260812-corpus-verification/` - compact live verification summaries for Blog and Customer Stories.
- `url-normalization/` - read-only URL normalization audit summaries and exception reports.
